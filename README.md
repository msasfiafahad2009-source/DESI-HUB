# 🍲 DESI HUB — Every Flavour Has a Story

**DESI HUB** is a Pakistani food and cooking website created to celebrate the rich culinary heritage of Pakistan. It brings traditional recipes, regional foods, spices, and kitchen essentials together in one place.

🌐 **Live Website:** https://msasfiafahad2009-source.github.io/DESI-HUB/

## ✨ Features

- **Home Page:** An attractive introduction to Pakistani cuisine.
- **Shop Products:** Explore spices, basmati rice, kitchen essentials, and traditional clay cooking pots.
- **Free Recipes:** Discover easy, step-by-step recipes, including Chicken Biryani, Potato Samosas, and Desi Style Chocolate Cake.
- **Traditional Foods:** Explore famous dishes from Pakistan's four provinces:
  - Sindh — Sindhi Biryani
  - Punjab — Sarson Ka Saag and Makki Roti
  - Khyber Pakhtunkhwa — Peshawari Chapli Kebab
  - Balochistan — Balochi Sajji
- **Best-Selling Products:** Discover featured kitchen products at affordable prices.
- **Shopping Cart:** View selected products, subtotal, discount, and final total.
- **Cooking Tips:** Learn traditional cooking techniques and helpful kitchen secrets.
- **Customer Reviews:** Read sample reviews displayed on the website.
- **About Us:** Learn about the mission of preserving Pakistani food culture.
- **Contact Us:** Find contact information and use the demonstration contact form.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layout, and visual design.
- **JavaScript** — Interactive website features.

## 🎯 Project Objectives

- To promote traditional Pakistani foods and cultural heritage.
- To provide free recipes for beginners and cooking enthusiasts.
- To showcase useful kitchen products at reasonable prices.
- To create an attractive and user-friendly cooking website.
- To introduce people to the diverse cuisines of Pakistan.

## 🚀 How to Run the Project

1. Open the repository on GitHub.
2. Click the **Code** button and select **Download ZIP**.
3. Extract the downloaded ZIP file.
4. Open the project folder in Visual Studio Code.
5. Open `index.html` in your browser, or use the Live Server extension.
